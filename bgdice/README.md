## 优化特性

### 1. 异步架构优化
- 消息处理与耗时操作完全分离
- 使用线程池处理图像识别等耗时任务
- 避免阻塞主线程，提高响应速度

### 2. 帧缓存机制
- 实现60秒帧缓存窗口
- 支持按时间窗口快速检索历史帧
- 提高特征提取准确性

### 3. 状态管理优化
- 游戏状态机更加健壮
- 支持状态恢复机制
- 处理消息丢失或乱序情况

### 4. 模块化设计
- 功能拆分到独立模块
- 降低模块间耦合度
- 提高代码可维护性

### 5. 特征提取增强
- 支持多帧输入输出组合
- 多背景图特征泛化
- 生成 INPUT × OUTPUT × M 个特征样本

## 使用方法

### 启动优化版服务器

```bash
python main_optimized.py
```

### 配置文件

配置文件仍使用项目根目录下的 `config.json`。

## 核心优化点说明

### 异步处理
所有耗时操作（如特征提取、模型推理）都通过 `asyncio.create_task` 或线程池异步执行，避免阻塞消息处理主线程。

### 帧缓存
视频帧按时间顺序缓存60秒，可根据需要调整缓存时长。通过时间窗口可以快速检索任意时间段的帧数据。

### 状态恢复
当收到消息但未找到对应游戏时，系统会尝试恢复游戏状态，确保不会因消息顺序问题导致处理失败。

### 特征泛化
通过组合多个输入帧、输出帧和背景图，生成更多特征样本，提高模型训练质量。
